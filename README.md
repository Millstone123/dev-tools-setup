# Dev Tools Setup

Automated development environment configuration utilities.

## Quick Start

Run the setup script to configure your environment:

```bash
npm run setup
```

This will install dependencies and configure necessary tools.

## Verification

After setup, verify everything is working:

```bash
npm run verify
```

## Notes

This project provides a simple setup mechanism for development environments.
